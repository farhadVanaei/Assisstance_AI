# دستیار عامل جواد (اولاما · آفلاین)

گفتگوی فارسی کاملاً محلی با **اولاما** + یادگیری اسناد و وب‌سایت با **خزشگر محدود به دامنه**.

## ساختار

```
JAVAD/
├── backend/
│   ├── main.py
│   ├── uploads/
│   ├── rag/ingest.py              # استخراج متن فایل
│   └── ollama_rag/
│       ├── client.py              # ارتباط با اولاما
│       ├── agent.py               # حافظه + بازیابی + گفتگو
│       ├── scraper.py             # خزش بازگشتی محدود به دامنه
│       └── text_clean.py
├── frontend/
│   ├── index.html
│   ├── css/styles.css
│   └── js/app.js
├── requirements.txt
└── README.md
```

## رابط‌ها

| روش | مسیر | توضیح |
|-----|------|--------|
| `POST` | `/api/rag/upload` | فایل و/یا آدرس وب → دانش محلی (وب: خزش دامنه) |
| `POST` | `/api/website/scrape` | یادگیری وب‌سایت با پیمایش لینک‌های داخلی |
| `POST` | `/api/ollama/chat` | گفتگوی فارسی با اولاما + زمینه |
| `POST` | `/api/memory/clear` | پاکسازی حافظه |
| `WS` | `/ws/voip-stream` | جایگاه صوت به متن |

## خزش وب

- فقط لینک‌های `<a>` که در **همان دامنه** آدرس ورودی هستند دنبال می‌شوند.
- عمق پیش‌فرض: ۲ سطح · سقف صفحات: ۲۰
- ناوبری، پاورقی، «پرش به محتوا» و آدرس‌های خام از متن حذف می‌شوند.

## اجرا (گام‌به‌گام)

### ۱) نصب و اجرای اولاما

```bash
# نصب از سایت رسمی اولاما، سپس:
ollama serve
# در ترمینال دیگر:
ollama pull llama3.2
```

مدل پیش‌فرض: `llama3.2`  
تغییر مدل: `export JAVAD_OLLAMA_MODEL=llama3`

### ۲) اجرای سامانه

```bash
cd /home/rome/PyCharmProjects/JAVAD
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

باز کنید: **http://127.0.0.1:8000**

۱. تب «مدیریت پایگاه دانش و وب‌سایت» — آپلود یا آدرس وب  
۲. تب «گفتگوی زنده با جواد» — گفتگو به فارسی  

بدون روشن بودن اولاما، گفتگو پیام خطای فارسی برمی‌گرداند؛ بارگذاری دانش همچنان کار می‌کند.
